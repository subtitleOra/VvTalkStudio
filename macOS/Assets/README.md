# 原生 macOS 应用图标

[VvTalkStudio.png](VvTalkStudio.png) 由内置 ImageGen 生成，保留透明背景。[VvTalkStudio.icns](VvTalkStudio.icns) 使用 macOS 的 `sips` 和 `iconutil` 从原图生成，供 Xcode 打包。

生成提示：

```text
Use case: logo-brand
Asset type: a single 1024×1024 raster macOS app icon for a speech prosody editor.
Create a very simple Apple-inspired app icon: one centered white, rounded, continuous pitch curve on a rich cobalt-blue rounded-square tile. The curve starts level, rises into one broad peak, dips into one shallower valley, then lifts and levels out. Use a bold stroke with rounded ends and generous breathing room so it reads at Dock size. Tile is straight-on with a restrained blue-to-indigo gradient, a subtle top-edge highlight, and no cast shadow. Center the tile within the square canvas; aim for about 82% canvas width and height, softly rounded macOS-style corners, and truly transparent pixels outside the tile. A crisp flat front view of just the icon. No letters, numbers, grid, microphone, music note, Apple logo, border, watermark, mockup, extra objects, or checkerboard drawn into the image.
```
