# VvTalk Studio 的 Figma 设计

设计文件：[VvTalk Studio](https://www.figma.com/design/R5pvrQSBdbLndCJaekhMEd/VvTalk-Studio?node-id=4-59)。页面 ID 为 `0:1`，页面名为“VvTalk Studio · 桌面工作台”。设计基于 VvTalk 的逐字时间轴与连续音高工作流；文字、曲线、波形、组件实例和布局均可在 Figma 中修改。

主编辑页尺寸为 1280 × 820。左侧以句子组织文稿，中间依次呈现文字输入、连续音高和逐字节奏，右侧负责目标引擎与语调参数。新建、打开和保存位于顶部，导出位于底部。示例文稿是“今天，我们一起回家吧。”，基准音高是 MIDI 61 / C♯4。画面采用 #F6F7F8 背景、白色卡片、#26332F 正文和 #237D69 操作色。中文使用 Noto Sans SC，品牌名使用 Inter。

## 本地组件与样式

已经检查文件中的现有界面与 Code Connect 入口：文件原先为空，代码没有匹配的 *.figma.* 映射。已调用 get_libraries，并在 Simple Design System 中合并搜索 button、input、background 和 body。按钮和输入框使用 Inter，正文样式为 Inter 16 px，背景变量采用通用语义体系。该体系与中文产品字体、操作色和参数区密度不匹配，因此建立了产品本地组件，没有套用 Material 组件。

| 本地组件 | 节点 | 可编辑属性 |
|---|---|---|
| Studio/Button | 3:39 | Variant、Label#3:0 |
| Studio/Input | 3:40 | Value#3:4 |
| Studio/Sentence | 3:50 | State、Title#3:5、Preview#3:8、Meta#3:11 |
| Studio/Syllable | 3:59 | State、Character#3:14、Pinyin#3:17、Duration#3:20 |

组件主件位于主编辑页下方，独立于交付的界面画板。颜色、间距和圆角绑定本地变量；文本采用 Studio/Caption、Body、Label、Title、Manuscript 五种样式。变量集合 `VariableCollectionId:3:2` 包含 25 个变量，语义颜色引用隐藏的原色变量，提供 CSS var() code syntax。正文与重复组件均使用共享文字样式。

## 实际检验

主编辑页、录音面板和导出反馈共 195 个节点：51 FRAME、109 TEXT、31 INSTANCE、4 VECTOR；整页图像节点为 0。目标引擎面板增加 17 个可编辑节点。所有文本的字体族均为 Noto Sans SC 或 Inter，已通过脚本断言。已分别截图检查四个状态，没有发现被裁切的中文、相互覆盖的文本或空图像占位。主屏截图显示连续音高、逐字读音和时长均完整可见，录音和导出状态的动作区完整可见。
