# 中文、日语和英语语调

文稿顶部和导入面板提供语言选择。中文按字调教，日语按拍调教，英语按词调教；保存文件、草稿、句设置、撤销和导出数据保留语言。已导入的录音曲线或 VSQX 锁定语言，要换语言请新建或重新导入，避免更换文字单位后继续使用旧时间区间。旧工程没有语言字段时按中文打开。

## 日语

本地 fugashi 与 UniDic Lite 提供形态分析、读音和词典重音核，假名转成逐拍单位。拗音如“きゃ”占一拍，长音、促音“っ”和拨音“ん”各占一拍；长音导出时换成前拍的母音读音，促音在音高草稿中保留无基频区间。汉字不会按中文拼音处理，例如“今日は”使用日语词典读音而不是三个汉字的中文声调。

表格可覆盖每拍假名和低/高，也可调整拍时长与停顿。词典中的词重音并不等于连续话语的最终重音，复合词、专有名词、语境和地区读法需要复核。遇到不认识的词或需要改变拍数的读音，可把正文中的该词写成假名后重新生成；API 同时支持按原文起点索引指定整词假名，但不要求普通用户填写接口字段。

## 英语

本地 CMUdict 提供 ARPAbet 音素、音节和词内重音；0 表示非重读，1 表示主重音，2 表示次重音。表格每行对应一个词，可以覆盖完整 ARPAbet 读音，例如 `HH AH0 L OW1`，再按元音音节填写重音。标点和句型参与句末升降调；词内重音、短语衰减与停顿生成连续音高。默认读音采用词典的第一项，异读词、姓名、未知词及语境重音要人工调整。未知词会明确显示未收录，不会把字母或猜测音素伪装成词典读音。

ACE 按音节发音，因此英语导出将多音节词的总时间区间细分为音节音符，保留原词的总时长和连续音高；工作台和 SV/VOCALOID 数据仍使用词单位。不同宿主的音素符号并不通用，英语 ARPAbet 覆盖保存在工程和元数据中，SV/VOCALOID 发音由各自词典重新计算。

## 录音与时间标注

Praat 基频提取与语言无关，但歌词单位和时间标注必须一致。日语 CSV/TextGrid 每个区间是一拍，可用对应平假名或片假名作标签；英语每个区间是一词，匹配时忽略大小写。CSV 使用 `lyric,start,end`，时间单位为秒；标签可省略，但数量、时间顺序与录音范围仍须正确。TextGrid 使用 IntervalTier，不能把整句或单个声学音素层当作词或拍的区间。录音开始的空白、音符间停顿及无声 F0 帧保留，提取出的绝对音高不会被文字语调覆盖。

自动对齐需要用户自行提供兼容的本地 MFA 环境、发音字典及声学模型。日英语音可上传人工或外部生成的 CSV/TextGrid；未配资源时可明确选择均分草稿，程序会显示其为估算时间。自动对齐缺资源或失败时不会偷偷均分，也不会换用普通话模型。英语自动对齐可通过 `VVTALK_MFA_EN_DICTIONARY` 和 `VVTALK_MFA_EN_MODEL` 指定与已有 MFA 2 环境兼容的英语词字典及声学模型；日语对应变量是 `VVTALK_MFA_JA_DICTIONARY` 和 `VVTALK_MFA_JA_MODEL`，其词条必须与逐拍假名读音匹配，普通日语逐词字典不能直接充当逐拍字典。未随包分发这些 MFA 资源。完整路径配置见 [README](../README.md)。

## 导出与验证范围

从 1.1.1 起，每次只导出所选引擎的一个工程文件。SVP 直接保存 Studio 2 原生 `pitchControls`；独立的剪贴板脚本可向已有工程写入 PitchControlCurve，不另落盘。ACEP 写入 CHN/JPN/ENG、对应声库与真实声音种子引用、分段 pitchDelta 和音节发音数据。VSQX 使用对应语言银行及未锁定发音，导入后选择该语言的已授权声库重新计算发音。需要保留工作台编辑信息时单独点击“保存工作台”，这会写入 `.vvtalk.json`，不会附带到引擎导出目录。

词典重音与句调属于可编辑的语调草稿，不保证自然话语的逐点复现；对照录音更适合还原实际说话的音高。公开记录分别说明数值检查、冻结 EXE、界面和实际宿主操作的范围，见 [公开验收概要](验收记录.md)。私人测试录音、宿主工程和 `.qa` 附件未随仓库发布。新日英音频尚未完成真人听感评价。
