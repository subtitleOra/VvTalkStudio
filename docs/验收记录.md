# 公开验收概要

这份记录公开可以说明的验收结论及其边界。开发期间的原始录音、宿主工程、桌面截图、机器路径和 `.qa` 记录不随公开源码发布；这里没有把私人附件改成失效的下载链接。仓库内的自动测试使用生成夹具，真实 MFA 测试必须由使用者显式提供自己的录音和本地资源。

## 1.1.2 界面与冻结程序

浏览器检查覆盖 1280×820、1000×700、800×560、640×451、480×360 和 400×300 六种尺寸，根页面滚动尺寸与视口一致。句子、编辑与参数面板分别处理内部溢出；窄窗口保留工作区横向滚动。键盘可到达右侧及底部控件，对话框、长状态路径和低高度句子列表完成了专项检查。

冻结 EXE 的自检通过，中文、日语和英语分别生成 13 个字、13 拍和 5 个词，所选引擎每次仅返回一个工程文件。英语 ACE 输出按音节扩展为 7 个音符，词的总时间范围不变。12 项服务与桌面回归检查通过。此前完整本机回归包含 66 项测试；公开副本的最终测试结果及二进制摘要应以该次 Release 随附记录为准。

1.1.2 原生窗口检查确认了新 EXE 身份、运行版本、冻结 CSS 与源码一致，以及原生窗口能够启动并提供可访问性节点。该轮未完成原生窗口截图视觉复核和窗口几何复核，因此六尺寸的视觉与滚动结论来自浏览器检查。不得据此宣称所有原生分辨率都已验收。

## 连续音高与宿主边界

此前中文 ACE 工程在 ACE Studio 中实际生成了试听音频，并执行宿主保存回读：9 个音符、2 条曲线通道，歌词与时间几何保持一致，音高最大浮点差为 3.658×10⁻⁶ 半音。此后默认 stock id / seed 命名空间修正和公开模板净化完成了离线结构、声种与导出语义检查；未切换现有未保存宿主去重新验证净化模板的打开、回存或试听。

SV2 正式脚本曾在本机导入并保存回读，13 个音符、3 条原生曲线、1398 个有声点的音高最大差为 1.994×10⁻⁶ 半音，时间差小于 1 纳秒。没有选择声库并执行试听。直接 SVP 输出的独立静态解码得到同一 1398 源点最大音高误差 0、最大时间误差 2.835×10⁻¹⁰ 秒；该检查不能替代新版直接 SVP 的宿主播放验收。

VOCALOID 6 的静态 VSQX 检查覆盖音符、PIT/PBS、清音与跨音符边界，1388 个有声采样点的最大误差为 0.0006710547 半音，即 0.06710547 音分，符合弯音整数编码的量化范围。真实 VOCALOID 6 启动被未授权声库提示阻断，未处理激活，也未执行导入或试听。VOCALOID 5 未安装，交付范围为兼容工程格式。

原版 VvTalk 实际生成的 VSQX 曾用于独立解码和同输入导出对照，最大差低于 0.074 音分。公开回归保留了独立 VSQX 解码器和程序生成的数值夹具，不包含原版导出器、Talker、缓存或私人宿主工程。比较方法与算法差异见 [对照说明](vvtalk-comparison.md)。

## 录音、语言与未完成项

中文的真实录音 → 本地 MFA 逐字对齐 → Praat F0 → 工程保存与导出链路已执行，并在冻结 EXE 中验证。原生文件选择、已知文字导入、逐字时间编辑、原音播放和保存也曾完成闭环。麦克风权限与硬件录音未实测。

日英文字单位、词典读音、重音覆盖、保存重开、手工标注、语言一致性和三引擎导出经过回归。日英录音导入的专项夹具使用人工均分标注和合成测试音频，验证的是数据与界面链路，不代表实际日英语音自动对齐、自然朗读或母语听感评价。自动对齐只有在本机提供兼容模型与字典时可用；缺资源不会替换为普通话模型或静默均分。

公开模板去除了个人库引用、旧工程身份、效果和加密元数据，保留必要的原生容器结构；该处理的结构与导出语义已核对。本轮没有新增净化模板的宿主试听。发行程序目前未签名，测试失败边界与正式签名条件见 [代码签名说明](code-signing.md)。
